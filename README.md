# Figcore — мини-Figma на WebAssembly

Исследовательский прототип, чтобы на практике понять, почему у Figma получается держать огромные документы в браузере: **ядро на компилируемом языке в Wasm**, **свой GPU-рендер**, **тонкий JS**.

## Как устроена Figma (и что мы повторили)

Публичные разборы (Evan Wallace и др.) сводятся к четырём решениям:

1. **Документ не живёт в JS.** C++ (у Figma) компилируется в Wasm. Дерево узлов, трансформации, hit-testing, undo — в линейной памяти модуля. JS вызывает команды (`create`, `move`, `select_at`) и забирает минимум данных для панелей.
2. **Свой рендерер.** Не DOM, не SVG, не Canvas 2D. Ядро готовит вершины/инстансы, JS отдаёт их в WebGL одним `bufferData`.
3. **Тонкий UI.** Кнопки, список слоёв, поля x/y/w/h — это обёртка, не модель.
4. **Свой бинарный формат файла**, не JSON.

Здесь то же самое, только вместо C++/Emscripten — **Rust `cdylib` с C ABI** (как у Figma: без wasm-bindgen, JS ходит в `exports` напрямую). Для сравнения рядом стоит **наивная копия**: объекты в JS-массиве и Canvas 2D.

```
┌──────────── JS (тонкий UI) ─────────────┐
│  toolbar / properties / FPS / bench     │
│         команды, не дерево              │
└──────────┬──────────────────┬───────────┘
           │                  │
    fig_create / pack    те же команды
           │                  │
   ┌───────▼──────┐    ┌──────▼──────┐
   │ Rust Wasm    │    │ Naive JS    │
   │ SoA документ │    │ objects[]   │
   │ hit / undo   │    │ hit / undo  │
   │ instance buf │    └──────┬──────┘
   └───────┬──────┘           │
           │ view на memory   │ fillRect × N
           ▼                  ▼
        WebGL2            Canvas 2D
```

## Возможности

- холст: зум (колёсико к курсору), пан (пробел / средняя кнопка / ПКМ)
- прямоугольники и эллипсы, группа выделенных
- выделение кликом и рамкой, drag, ресайз за 8 ручек
- цвет, undo/redo, Delete
- свой бинарный формат `.mfg` (магическая шапка `MFG1`)
- генерация 1k / 10k / 100k / **1M / 10M / 100M** (от 250k — процедурный слой: в памяти только seed и счётчик, на экран — LOD-выборка)
- счётчик FPS / время кадра / время `pack`
- кнопка **«Замерить 3с»** — автопан, строка в таблицу
- переключатель **Wasm + WebGL2** ↔ **JS + Canvas 2D** (сцена копируется тем же бинарником)

## Запуск

Нужны **Rust** (`rustup`, target `wasm32-unknown-unknown`) и **Node.js**.

```powershell
cd mini-figma
.\build.ps1          # ядро → web/figcore.wasm
npm start            # http://127.0.0.1:4173
```

Открывать `index.html` с диска нельзя: браузер не даст инстанцировать Wasm.

Клавиши: `V` выделить, `R` прямоугольник, `O` эллипс, `Ctrl+Z` / `Ctrl+Y`, `Ctrl+A`, `Ctrl+G`, `Ctrl+0` сбросить вид, `Delete`.

## Что смотреть в коде

| место | роль |
|---|---|
| `core/src/lib.rs` | документ (SoA), hit-test, undo, сериализация, упаковка инстансов |
| `web/wasm-bridge.js` | тонкий FFI, `Float32Array` *view* на память Wasm |
| `web/gl-renderer.js` | WebGL2 instancing, сетка, ручки |
| `web/naive.js` | та же модель и тот же `.mfg`, но объекты в JS и Canvas 2D |
| `web/app.js` | UI, камера, жесты, бенч |

Отчёт с цифрами и выводами: [`REPORT.md`](REPORT.md).
